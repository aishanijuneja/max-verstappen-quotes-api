# Max Verstoppen


Welcome to the **Max Verstoppen** API! This API provides a collection of quotes from F1 driver Max Verstappen, inspired by his humorous remarks following his FIA punishment.


## Features


- Retrieve random quotes from Max Verstappen.
- Easy to use and integrate into your projects.
- Lightweight and fast.


## Getting Started


### Installation


To use the Max Verstoppen API, clone the repository and install the required dependencies:


```bash
git clone https://github.com/your-username/max-verstoppen.git
cd max-verstoppen
npm install
```


### Usage


You can access the API endpoints as follows:


1. **Get a Random Quote**
   - **Endpoint**: `GET /api/quote`
   - **Response**: A random quote from Max Verstappen.


### Example


```bash
curl -X GET http://localhost:3000/api/quote
```


### Sample Response


```json
{
  "quote": "Thank you, Danny."
}
```
